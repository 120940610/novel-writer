## 一、世界观设定

### 1.1 全书核心定位与叙事底色

- 题材：武道爽文／仙武双修／穿越逆袭／群像传奇
- 总字数：约 230 万字，430 章，七卷
- 结构：七卷推进，卷六《天幕之下》揭上古真相，卷七《道不远人》收终战、渡劫与飞升
- 基调：豪爽重情、热血逆袭、体系革新、广结善缘
- 冲突核心：不是天道降罚或系统博弈，而是人与人、势力与势力、道路选择之间的现实博弈

### 1.2 世界大背景（历史纵深）

- 上古时期，修真界曾发生一场大乱——宗门倾轧、资源争夺、战火蔓延。
- 大量顶级功法在战乱中失传，传承断绝，精英修士死伤惨重。
- 大乱之后，修真界元气大伤，功法质量一代不如一代，修行效率越来越低。
- 飞升从"极难"变成了"几乎不可能"——**不是有人封印了飞升之路，而是功法本身已经残缺到无法支撑修士走到那一步**。
- 当下修真界表面仍繁华：宗门林立、百家争鸣、丹药法器流通兴盛；但真正完整的顶级功法早已失传。
- 化神者已极稀少，渡劫者几乎绝迹，大乘飞升更是千万年无一例可考。

### 1.3 世界观硬边界（锁定条款）

1. 武神称号 = 大乘/飞升层级，为全书最高战力天花板。
2. 任何角色不得感知/触碰/对抗/掌控/改写天道法则。
3. 不存在"天道化身""终极大Boss""飞升封印"。
4. 不存在任何系统类金手指。
5. 叙事冲突来自人与人、势力与势力、道路选择之间的现实博弈。

### 1.4 修行生态与规则体系

#### 1.4.1 武道体系地位

**武道的历史断层与现实困境：**

- 上古大战导致武道传承近乎断绝。先天以上的高阶武道修炼功法极为罕见，现存多为残缺或后人补全。
- **关键设定**：现世武者手里的高阶武道功法**全是残篇，而残缺处恰恰是每一大境的破境关窍**——他们练得再苦，也常常卡在门前不知门在何处。楚尘手握上古**完整**传承（残魂所传《武道真解》全本、太初城武道火种、断岳石碑、《身为炉》下半部），破境关窍一节不缺，这是他**无法被复制的核心底蕴**，也是他每一次突破都能水到渠成、成境后又比同阶偏强一档的根本原因。
- 正因功法稀缺、修炼条件苛刻，高阶武道修士极为稀少。习武者多为无法修仙的低阶修士——灵根不足、灵根被废、或无灵根者退而求其次的选择。
- 在仙道宗门掌握话语权的大陆格局下，武道长期被视为"下等修行""废灵根者的末路"，在主流修行界缺乏尊严与地位。

**武道本身的优势：**

- 武道最大的优势：**同级武道碾压同级修真**（锁定条款，机理见 3.1.1）——武道无灵气可借，一切劲力出自己身，故出手更快、抗打更实；仙道的护体灵光、符箓、法器都要起手与调气的工夫，同阶之下必被武者抢先。
- 武道修炼极苦，需同时满足：**完整功法传承（破境关窍不缺）＋刻苦练习＋天材地宝淬体＋练体丹药辅助＋奇遇机缘**，缺一不可。
- 武道者凤毛麟角——整个东土大陆真正的武道修炼者不超过万人。
- 武道不依赖外部灵气可自成一炉，因此在高压、绝灵、封锁环境下更具韧性。

**楚家的武道空白：**

- 楚家是苍云城纯仙道修炼家族，族中百年从未有人走过武道路线。主角楚尘在楚家环境下走上武道，是反常且孤立无援的——没有家族功法传承、没有长辈指点、没有同辈切磋，一切从零开始。这一背景使主角的武道之路在卷一开局即背负双重困境：外有仙道宗门打压，内有家族环境孤立。

#### 1.4.2 修真体系地位

- 修真者人数众多、体系完整——七大仙宗为首的修真体系掌控着大陆话语权。
- 主流修行界奉行灵根、灵脉、宗门、资源垄断逻辑。
- 旧时代修真功法残缺，却凭借组织与资源优势压制新道路的出现。

**能力分界：炼气期不可离地飞行（锁定条款）**

- **炼气期没有御空飞行能力**——不能凌空停驻、不能腾空久驻、不能御剑载人飞行。这一条是硬设定，全书不得破例。
- 炼气修士能做到的上限只有四样：① 借法器短距腾跃（一跃数丈，落地即止）；② 踏墙走檐、借力借势的轻身功夫；③ **御飞剑攻击**——剑离手飞出去伤人可以，人骑上去飞不行；④ 以灵气缓冲跌落，坠高不死。
- **离地飞行是筑基期才开始具备的能力**。这条分界是凡俗世界的定盘星：修士比凡人强得看得见（术法、护体灵光、飞剑、寿元），但没到"腾云驾雾"的神话程度。
- 由此推出的世俗观感：绝大多数宗门执事、家族子弟终身停在炼气，一座凡间小城里"能飞的人"通常一个也没有；**筑基修士当空落下，本身就是全城仰头的大事**——楚尘卷一至卷二所见的仙道威压，量级到此为止。
- 炼气期共分九层（前期一至三层、中期四至六层、后期七至九层，九层即炼气圆满），层数换算与武道对位见 2.2、2.3.1。

#### 1.4.3 仙武双修的独特性

- 仙武双修是楚尘独有路径——以武道的"肉身为炉"补全仙道功法残缺，两者互补而非对抗。
- 混沌灵根被唤醒后，楚尘可以通过武道金丹/道域承接灵气，再反哺肉身与真力。
- 这一体系最终发展为可普及的全新道路，即卷终开创的"混沌道经"。

### 1.5 大陆格局、空间层级与视野扩展

#### 1.5.1 空间格局

- **凡间小城**：苍云城、楚家、荒山遗迹，是主角遭遇退婚、逐出、得传承的起点。
- **边境险境**：青石关、裂天峡谷、太初城废墟，关联上古战役遗址、武道火种、断岳石碑与丹武突破。
- **王国/宗门层**：大风国、青云宗、天刑台、大夏王朝，承接家国、宗门、仙门冲突。
- **大陆层**：东土王城、万脉大比、东土仙盟、北境妖族、黑市情报网，完成群像扩张与万脉争雄。
- **禁忌遗迹层**：上古战场、地宫、杀阵、上古守护者传承，揭开上古大乱真相与新功法根源。
- **飞升层**：破碎虚空、天劫、大乘、飞升光柱与更高层次世界。

#### 1.5.2 视野扩展路径

凡间小城（卷一，明暗化劲/炼气视野）→ 边境险境（卷二，先天-丹武/炼气视野）→ 王国仙门（卷三，丹武/炼气-金丹视野）→ 大陆舞台（卷四，元武/元婴视野）→ 大陆争雄（卷五，神武/化神视野）→ 上古遗迹（卷六，神武圆满/化神圆满视野）→ 终战、渡劫与飞升（卷七，圣武/渡劫-大乘视野）

### 1.6 地理、遗迹与关键场所

- **苍云城**：主角出生与受辱之地，也是武道联盟的最初根基。
- **楚家**：主角家族，卷一前期打脸与脱离的重要场所。
- **城外荒山**：残破法宝与上古残魂所在之地，主角命运转折点。
- **青石关**：卷二越境节点，象征主角从小城视野跨向东土。
- **裂天峡谷**：上古惨烈战役遗址，终年雷暴（地脉与灵气紊乱所致的当地天象，与谁站在下面无关），藏有断岳石碑、武神祭坛、丹武突破机缘。**峡谷之雷与祭坛落雷一律定性为"天象＋遗迹阵纹导引"，不是天劫、雷劫或天罚**（见 3.4.4）。
- **太初城废墟**：地底密室存有"武道火种"与上古武道完整知识体系。
- **青云宗**：主角前期压迫与阴谋核心，林玄机被囚于天刑台。
- **天刑台**：青云宗酷刑与旧秩序暴政的象征，也是卷三高潮战场之一。
- **大风国皇城**：赵无双设宴、武道联盟公开站位的重要地带。
- **大夏王城**：宫廷政变、太子登基、上古秘卷出世之地。
- **万脉大比会场**：武道第一次公开登上大陆最高舞台。
- **陨星谷**：卷五最惨烈战场之一，武道联盟伤亡近半。
- **禁忌之地／上古战场遗迹／上古地宫**：卷六核心舞台，真相揭示、铁牛断臂、新路开辟之地。
- **飞升台／飞升光柱前**：楚尘向众生告别、完成主题升华的终局舞台。

### 1.7 势力与阵营设定

#### 1.7.1 现世势力

- **楚家**：主角的原生家族，也是其被排斥与脱离的开端。
- **青云宗**：前中期主要反派宗门，囚禁林玄机、推动诛武打压。
- **大风国**：凡间政治盟友，赵无双长期提供后勤与政治支持。
- **大夏皇室**：更高层世俗权力中枢，太子一线与楚尘结盟。
- **东土仙盟**：大陆修真秩序代表，后期因武道崛起而成立"诛武盟"。
- **诛武盟**：三位化神前期太上长老统领，代表既得利益对武道与新路的围剿。
- **武道联盟**：从苍云城约 2400 人扩展到 5000、3 万、5 万余弟子的跨区域组织，是主角理念与情义的实体化。
- **北境妖族**：以拓跋野为纽带，从对手转为盟友的重要力量。
- **黑市情报网**：由温不二入局后逐步扩张，成为武道联盟的耳目系统。

#### 1.7.2 上古遗留与高层力量

- **上古武道传承链**：残魂、断岳石碑、武道火种、武神祭坛、上古完整功法构成主角承脉线。
- **仙界巡天体系**：以白虹为代表，最初承担观察与压制功能，后逐渐理解楚尘之路。
- **守护者一脉**：姜牧所属传承，负责看守上古战场遗迹与地宫真相。
- **观界者／天幕／彼岸之影／道种母树等线索**：归入终局真相层（卷六至卷七），用于解释更深层次的窥视、筛选、收割与上古残存秘密，但不凌驾于前述世界观硬边界之上。

### 1.8 上古背景与传承设定

- 上古大乱的核心，并非天道惩罚，而是**顶级宗门争夺天地灵脉、彼此倾轧，最终造成修行文明断层**。
- 各大宗门核心功法典籍在战火中被毁，完整修行路径自此崩塌。
- 残魂所传，是上古武道最后一脉完整传承之一。
- 断岳石碑完整记录丹武突破的三才条件，是卷二关键升级节点。
- 太初城地底密室中的"武道火种"，代表上古武道大宗师留下的系统化知识遗产。
- 上古秘卷由大夏皇室交给楚尘，指向大乱真相与功法断层源头。
- 卷六中，楚尘将残魂所传、个人摸索的仙武双修之路、对灵气与肉身的理解三者融合，创造全新功法体系。

### 1.9 主角起点设定

- 楚尘来自地球，穿越重生至修真世界，转世于苍云城楚家。
- 他没有带来任何超自然能力——只有现代人的开阔思维和对世界规则的旁观者视角。
- 开局三连打击：被未婚妻叶清雪以"灵根枯竭废物"为由退婚 → 被家族族人嘲讽为废物 → 被赶出楚家主宅。
- 绝境中，楚尘在城外荒山偶然捡到残破法宝，得到上古武道大宗师残魂传功。
- 全书不存在任何系统设定；楚尘完全靠自身意志、刻苦修炼、悟性与机缘成长。

## 二、境界体系（锁定版）

### 2.1 武道阶梯（完整）

明劲 → 暗劲 → 化劲 → 先天 → 丹武 → 元武 → **神武 → 圣武**（共 8 大境）

- 每大境：前期 → 中期 → 后期 → 圆满 四小阶
- **武神 = 圣武圆满后的尊称**（非独立境界）
- 武道特点：修意志、修肉身、修真力；不依赖天地灵气可自成一炉

## 三、力量对比／战力关系矩阵（锁定版）

### 3.1 同阶战力

| 武道 vs 仙道（同阶对位） | 判定 |
|---|---|
| 明劲 vs 炼气一至三层 | 武道强 |
| 暗劲 vs 炼气四至六层 | 武道强 |
| 化劲 vs 炼气七至九层（含炼气圆满） | 武道强 |
| 先天 vs 筑基 | 武道强 |
| 丹武 vs 金丹 | 武道强 |
| 元武 vs 元婴 | 武道强 |
| 神武 vs 化神 | 武道强 |
| 圣武 vs 合道/渡劫 | 武道强 |

**通则**：武道天然比同阶仙道略强（同阶碾压）。原因：武道意志压制场干扰对方灵气调动，且真力可自成不依赖外部灵气。

#### 3.1.1 同境界武道碾压仙道（锁定条款·全书核心特色）

**条款**：同一对位境界上，**武者对修士，先赢一半**——武道对同阶仙道是稳定的压制关系，不是"略占优势"，而是"同阶必胜"。这是全书最重要的差异化设定，任何战斗描写不得反写。

**机理（写作时必须落到下面几条上，不许只写结论）**：

1. **劲力出自己身，没有取用环节**。武道无灵气可借，一身劲力全在血肉筋骨与气海之内，念到即出；仙道修士的每一记术法都要先调灵气、再走经脉、再成形。**同阶之下，武者永远抢先半拍**——差的就是这半拍。
2. **抗打更实**。武者的肉身是拿药浴、桩功、天材地宝一寸一寸淬出来的，护身靠的是自己的骨头；修士护身靠护体灵光与法器，灵光一破就是血肉之躯。所以同阶对拼，武者敢换命，修士不敢。
3. **意志能成场，压制对手的灵气调动**。武道修到暗劲以上，意志外放成压迫场——修士在这个场里调气会滞、起手会慢、符箓会哑，越是依赖外物的修士越难受。**这不是"法术无效"，是"起手慢了半拍、灵气涩了一分"**，写作时把量级写在"滞涩、慢半拍、灵光薄一层"上，不要写成"术法完全失效"。
4. **时间成本是仙道的死穴**。护体灵光要起手、符箓要引燃、法器要认主催动、阵法要布——每一样都要工夫。同阶之下，武者一步抢进，这些工夫全被吃掉。

**反面限制**：这条只在**同一对位境界**上成立。跨阶时一律受 3.3.1 的硬顶约束——武道的优势能让他越阶，但越不过 3.3.1 的三条上限。修士若境界高出足够多（灵光够厚、术法够快、有阵法与人手），武者的"抢先半拍"就不够用了。

| 楚尘双线阶位 | 综合战力等效 | 备注 |
|---|---|---|
| 化劲圆满＋无仙道 | ≈ 化劲圆满（可胜炼气圆满／炼气九层；对筑基初期较弱修士可勉强斗一斗，须搏命负伤） | 卷一末 |
| 丹武前期＋炼气一层 | ≈ 金丹早中期偏上 | 卷二末 |
| 丹武圆满＋金丹圆满 | **≈ 金丹圆满偏上，可险胜同阶元婴前期** | 卷三末 |
| 元武圆满＋元婴圆满 | **≈ 元婴圆满偏上，可险胜化神前期** | 卷四末 |
| 神武圆满＋化神圆满 | **≈ 化神圆满偏上，可险胜合道前期** | 卷五末 |
| 圣武前期＋化神圆满 | **≈ 圣武前期偏上，可抗衡合道前期不落败**（叠加折扣：仙道未至合道） | 卷六末 |
| 圣武圆满＋大乘 | **武神尊称，同阶碾压合道/渡劫，接近仙人层级** | 卷七末 |

**通则**：仙武双修叠加后，主角综合战力比"武道或仙道单线圆满"要**超出一个大境界**——即"双线同阶圆满"可越级挑战对手单线的下一大境前期。

**同阶偏强通则（锁定）**：楚尘每破一境，因底蕴远厚于现世同阶（上古**完整**传承＋苦修的绝对量＋药材外物），其新境根基天然**比同阶偏强一档**——结实一档、劲厚一档、根基干净一档。写作时须以**同阶对照**（与同境武者/修士正面比较）或**旁人评价**落地，不得只写结论。**突破本身不带来任何虚弱期或折损**，故不存在"刚破境所以更弱"的窗口。

### 3.3 越级战力规则（硬约束）

本规则是全书战力判定的最高约束，任何战斗描写必须严格遵循。

#### 3.3.1 单线武道越级能力（天然优势）

主角只走武道时（或仅武道进境高于仙道时），凭借意志压制场对灵气调动的干扰，天然具备"以武道单线越级抗衡仙道"的能力。

**A. 明暗化劲的跨阶上限（硬约束·逐条锁定，不得突破）**

卷一至卷二前半（楚尘未开仙道时）的一切交手判定，以下三条为**硬顶**，任何战斗描写不得越过：

| 武道境 | 可胜（能打赢、能拿下） | 可抗衡（不落败但难取胜） | 不可越过的红线 |
|---|---|---|---|
| **明劲巅峰**（明劲圆满） | **炼气四层** | **炼气五层** | 不得打赢炼气五层及以上；炼气六层以上只能逃 |
| **暗劲巅峰**（暗劲圆满） | **炼气七层**（即化劲对位的炼气后期起点） | **炼气八层** | 不得打赢炼气八层及以上；炼气九层（炼气圆满）当面全力压制时只能被压 |
| **化劲圆满** | **炼气圆满（炼气九层）** | 可**勉强**与**筑基期初期的较弱修士**斗一斗——"斗一斗"＝有一战之力、非稳胜，且须付出搏命与负伤 | 不得稳胜任何筑基修士；不得战胜筑基中期及以上 |

**判定用语的准确含义（写作时按此落笔，不许含糊）**：

- **可胜**＝正面交手能拿下，但仍要有过程、有代价（挂彩、力竭），不是一拳了事。
- **可抗衡**＝打得住、不落败、能周旋能脱身，但**取胜要靠对手失误、环境助力或盟友牵制**，不能凭本身战力硬赢。
- **斗一斗**＝有一战之力，非稳胜；必须写明搏命与负伤，且交手结果允许是重创迫退、两败俱伤、或借环境险胜，不允许写成干净取胜。
- 未至巅峰的小阶按 2.3.1 的层数对位向下推移（如明劲中期对位炼气一至二层，其跨阶能力相应减半），**一律不得超过本表三条硬顶**。

**通则（锁定）**：以上是**单线武道**的越阶上限。仙武双修叠加后的越阶能力仍按 3.3.2 执行；但 3.3.2 的任何判定**不得与本条的武道单线上限自相矛盾**——即在楚尘仙道尚未成气候的阶段（卷一全卷、卷二丹武之前），一切战斗按本表硬顶走，不得借"双修加成"提前突破本表。

**B. 先天／筑基及以上的越级幅度（小阶递推）**

先天对筑基起，仙道恢复"前期→中期→后期→圆满"四小阶，越级幅度按小阶递推：

| 武道大境**同小阶** | 对位仙道 | 判定 |
|---|---|---|
| 武道任意小阶 vs 同阶仙道 | 同大境同小阶 | **碾压**（同阶必胜） |
| 武道**前期** vs 仙道**中期** | 越半阶 | **抗衡不落败**，可**小胜较弱的仙道中期者** |
| 武道**前期** vs 仙道**后期** | 越大半阶 | **抗衡不落败**，胜负难分 |
| 武道**前期** vs 仙道**圆满** | 越一阶圆满 | **极限逃命**，只求存活，胜机极稀 |

> **推演**：武道中期/后期/圆满对同阶仙道的越级幅度依此推移（如武道中期 vs 仙道圆满 ≈ 抗衡不落败；武道后期 vs 仙道圆满 ≈ 抗衡偏优；武道圆满 vs 仙道圆满 ≈ 同阶碾压加成）。本推演只适用于**先天／筑基及以上**；明暗化劲对炼气九层，一律按上面 A 表的三条硬顶判定。

#### 3.3.2 仙武双修叠加越级能力（按武道大境分级）

主角进入仙武双修后，双线力量互相加成，越级能力**按武道所处大境分级递增**：

| 双修组合（武道大境＋仙道大境） | 越级能力上限 |
|---|---|
| **丹武（任意小阶）＋金丹** | **同大境无敌**，可打败普通**金丹圆满**修士；越到元婴前期需搏命＋负伤，非常态 |
| **元武（任意小阶）＋元婴** | 可越**一个大境**，最多打败**化神前期**修士 |
| **神武（任意小阶）＋化神** | 可越**一个大境**，最多打败**合道前期**修士 |
| **圣武（前中后期）＋合道/渡劫** | 可越**一个大境**，可挑战**渡劫前期** |
| **圣武圆满（武神尊称）** | 全书武道天花板；越大境能力接近仙人层级，与合道/渡劫/大乘者正面抗衡 |

> **重要说明一**：主角在**先天阶段**仙道刚起步，双修叠加体系**尚未成型**，此阶段越级幅度仍以"单线武道越级"规则为主，双修加成只是让战斗更稳、消耗更小，并未打开"越大境"的门。**双修叠加"打开越大境能力"从丹武＋金丹起真正生效。**
> **重要说明二**：若主角仙道进度落后于武道（如卷三大部分时间处于"丹武＋筑基"状态），叠加效果按折扣判定——越级作战以"抗衡不落败/迫退"为上限，不适用"打败下一大境前期"的完整叠加规则。卷三太虚之战（第 163 章）与卷七前期（圣武＋化神圆满、合道突破前）均按此口径执行。
> **重要说明三（锁定）**：本表与 **3.3.1 A 的武道单线跨阶上限不得自相矛盾**。丹武＋金丹之前（卷一全卷、卷二丹武之前），楚尘的一切越阶判定以 3.3.1 A 三条硬顶为准，双修加成不得用来提前打开越阶空间；丹武＋金丹之后，本表生效，但每一次越大境仍受 3.3.3 硬约束（搏命、负伤、非常态）。

#### 3.3.3 硬约束（全书通用红线）

1. **越大境作战必须以搏命/险胜为前提**，绝不允许"轻松碾压"越大境对手；每一次越大境的胜利都必须写明：搏命过程、战斗内伤/道基损耗、短时不能再战、盟友牵制、环境助力等。**（以上均为战斗结果，属战斗代价，与突破无关；严禁写成"因为刚突破所以虚弱/反噬"。）**
2. **越两大境**：任何情况下都**仅能迫退/逃命，绝无秒杀**。哪怕依托"仙武共鸣""武道道域""混沌之力"等特殊功法叠加环境＋盟友，结果最多是**重创迫退或全身而退**，绝不写"击杀两大境高手"。
3. **越三大境及以上**：仅有"混沌之力"级别的还原性法则可短时压制，且必以自身道基受损为战斗代价，非常态、不连发。
4. **突破铁律不因越级战场而豁免**：战场上的任何破境同样必须满足 3.4 四条（深厚底蕴＋具体奇遇/贯通契机＋水到渠成＋成境后同阶偏强），严禁"临阵开挂式越级破境"，也严禁以"付出代价"充当破境的理由或后果。
5. **对反派同规则适用**：反派也不得违反本规则轻松压制越大境对手，除非明确设定为"混沌之力标记的代理人"等已注明的特殊存在。
6. **明暗化劲跨阶硬顶不可破**：卷一至卷二前半的一切交手，一律不得越过 3.3.1 A 表三条上限（明劲巅峰可胜炼气四层／抗衡五层；暗劲巅峰可胜炼气七层／抗衡八层；化劲圆满可胜炼气圆满、勉强斗筑基初期较弱者）。"明劲武者打赢炼气六层""化劲稳胜筑基""化劲圆满斩杀筑基中期"之类的战果一律不写。
7. **动静量级与来源**：任何战斗、突破、遗迹激活的动静都必须与境界相称，并写清来源，详见 3.4.4。低境界不得引发天地级异象；除飞升渡劫外，全书不出现雷劫与天罚。

> **口径提示**：本节所列"搏命／负伤／内伤／道基受损／短时不能再战"一律为**战斗代价**，属战力平衡红线，**照写照留**；与 3.4 所禁的"突破代价"是两回事——判定标准见 3.4.3。越级挑战的层数红线（越一大境／越两大境／越三大境）同样不得放宽。

### 3.4 突破铁律（锁定条款）

> **本节为全书最高优先级锁定条款，优先于本文件其余一切条款与旧稿表述。**
> **铁律原文**：主角楚尘每一次境界突破，都必须体现为**深厚底蕴积累或真实奇遇、水到渠成**，而不是勉强突破；**突破没有任何代价或后遗症**；突破后实力在同阶中**属于偏强一档**。

#### 3.4.1 四条必备要件（每次突破逐条落地）

| # | 要件 | 落地要求 |
|---|---|---|
| 一 | **底蕴要厚** | 突破的根只在三样：① **上古完整武道传承**——残魂所传《武道真解》全本、太初城武道火种、断岳石碑、《身为炉》下半部；**现世武者手里全是残篇，缺的恰是破境关窍**，这是楚尘无法被复制的核心底蕴；② **苦修的绝对量**——年头、拳桩次数、药浴回数必须给得出具体量级（如"两年苦修、万次桩功、药浴近两百回"）；③ **药材与外物**——真金白银换来的、九死一生取回来的，须写明来路 |
| 二 | **契机是奇遇或豁然贯通** | 必须是具体、有分量的事件，至少落实其一并写实：古洞传承、石碑心法、上古地宫/祭坛所得、上境强者以真力（灵压）灌体让他**亲身看见上境风景**、把背了很久的那一节**忽然看懂**、两条道（武道/仙道）互证而通 |
| 三 | **过程水到渠成** | 突破当场**顺、稳、痛快**；可写骨节爆响、真力酣畅、气海轰鸣。**不写苦熬硬顶、不写九死一生才勉强挤过去**。**动静必须与境界相称——低境界突破不得引发天地级异象**：明暗化劲的突破，动静止于一室之内（骨节响、劲风掀翻茶碗、震落屋瓦、桩下石板皴裂）；先天至元武，动静止于院落与山谷（气浪、地面开裂、方圆数十丈可感）；神武以上方可写更大场面，且一律按 3.4.4 写清来源 |
| 四 | **无代价，突破后偏强** | 突破本身不产生任何身体或修为的负面后果；新境根基在同阶中**偏强一档**——结实一档、劲厚一档、根基干净一档，须以**同阶对照**或**旁人评价**落地 |

#### 3.4.2 禁令（红线）

1. **禁含糊契机**：严禁"练得差不多了顺势突破""时机成熟自然突破""水磨工夫到了""感觉快了"这类交代不清的写法。
2. **禁勉强破境**：严禁"硬撑破关""苦熬硬顶""咬牙硬提境界""九死一生才勉强挤过去"。
3. **禁突破代价**：全书不得出现因**突破本身**而产生的**代价／反噬／损耗／后遗症／恢复期／真力枯竭／灵力枯竭／经脉受损／道基虚浮／金丹裂纹／修为倒退／回落半阶／虚弱期／短时不能再战**等任何表述。
4. **禁越级破境替代底蕴**：不得以"付出代价"或"临阵开挂"替代底蕴与契机的交代（并见 3.3.3 第 4 条）。
5. **境界阶梯约束不变**：突破仍不跨小阶、不跨大境（见 2.1／2.2 与 12.1）。

#### 3.4.3 保留项（属剧情代价，不在本节清理范围）

| 保留类别 | 说明 | 例 |
|---|---|---|
| **战斗受的伤** | 越级搏命、以一敌多所受的内伤、带伤、道基受损、短时不能再战——属**战斗结果**，照写照留 | 卷二第 119 章重创元婴后带伤；卷三第 156、165 章越级搏杀负伤；卷五第 282 章越级道基严重受损 |
| **渡劫／大战的伤** | 天劫加身的肉身裂纹、七窍流血，终战鏖战的消耗——属**天劫与战阵之伤**，照写照留 | 卷七第 409 章刀兵劫肉身裂纹；第 411 章七窍流血 |
| **剧情牺牲与损失** | 为救人付出的代价、势力被围剿、亲友伤亡——照写照留 | 铁牛断臂护关（第 355 章）；陨星谷伤亡近半（第 278 章）；韩铁山传讯而亡（第 64 章）；林玄机受刑道基尽毁 |
| **其他人物的代价** | 配角、反派突破或强行提升所付的代价，**照写照留**——正因有此对照，才更凸显楚尘底蕴之厚 | 太虚献祭寿元申请诛武令（第 128、176 章）；顽固派以法宝强撑（第 382 章）；旧秩序修士靠残篇苦熬而不得寸进 |

> **判定口径（一句话区分）**：凡负面后果的因由是"打了一场""渡了一次劫""为别人挡了一下""被人施刑"，一律**保留**；凡因由是"他刚破了一境"，一律**删除**。

#### 3.4.4 动静的量级与来源（锁定条款）

**总则**：**动静的量级必须与境界相称，且每一处动静都要写清来源。** 宁可写小、写实、写具体，不要写大而空。

**一、量级阶梯（写作时按此封顶）**

| 层级 | 动静的上限 | 可写的具体物象 |
|---|---|---|
| 明劲／暗劲／化劲 | 一室、一擂台、一条街之内 | 拳风炸出闷响、震落瓦片、打断石柱、地砖皴裂、在场修士的灵气一瞬滞涩、护体灵光起手慢半拍 |
| 先天／丹武 | 一座院落、一段山谷；方圆数十丈 | 真力冲击掀起气浪、屋梁落灰、地面开裂、马匹惊蹶、数十丈内草木倒伏 |
| 元武／神武 | 一片战场；方圆数里 | 意志成场压得对手调气发涩、道域覆盖战场、地脉轻微震动 |
| 圣武／合道以上 | 可写大动静，但**必须有出处** | 新道则出世引发的道韵扩散、道种母树本源回应、上古遗迹整体激活 |

**二、来源三分法（每处动静必须归到其中一类，并在文中点明）**

1. **遗迹的**——上古祭坛、阵纹、地宫、道种母树被激活而产生的气浪、地脉震动、光柱。**这是遗迹之力，不是人物的力量**；写作时要让人物本人也知道"这动静不是我打出来的"。
2. **道则的**——新道则出世、道韵扩散、法则共鸣、道种母树本源反应。仅限圣武／合道以上、且与《混沌道经》创成一线相关的场合。
3. **他自己的拳**——武者劲力、真力冲击、意志压迫场。量级严格按上表封顶，**绝不外溢成天象**。

**三、禁写清单（全书红线）**

- **禁"天地异象""异象震天""天地为之变色""异象四方汇聚"**等无出处、无量级的空话，一律改为有来源、有物象的具体描写。
- **禁低境界引发天象**：楚尘在化劲、先天、丹武阶段的任何出手与突破，都不得引动云层、不得改变天色、不得让天地为他作反应。
- **禁"雷劫""天罚"**：除**飞升渡劫**之外，全书任何场合不得出现雷劫、天罚、天谴。
  - **保留项（明确）**：卷七第 404-415 章的**九道天劫**属飞升渡劫设定，照写照留；1.5.1 空间层级中的"飞升层：破碎虚空、天劫、大乘、飞升光柱"为世界观层级设定，保留；卷七渡劫之伤（第 409、411 章）保留。
  - **裂天峡谷与武神祭坛之雷的定性（锁定）**：裂天峡谷**终年雷暴**是当地天象（地脉与灵气紊乱所致，与谁站在下面无关）；武神祭坛是上古遗迹，其阵纹被拳劲激活后会把峡谷雷暴之力顺纹导下——所以卷二第 78 章的三道落雷、第 106-110 章的九道落雷，**都是"峡谷天象＋遗迹阵纹"的产物，属遗迹之力与自然雷暴，不是天劫、不是雷劫、不是天罚**，与楚尘的境界高低无关（换个人上祭坛，雷同样会落，只是接不住）。写作时须借人物之口把这层来路点明。
- **各方势力"侧目"的正确写法**：不写"天地为他变色，众人皆惊"，改写**看见了什么**（遗迹方向的光柱、峡谷方向连日不散的雷云、地脉震动传到百里外的驿站）或**收到了什么**（探子回报、传讯符、商队口耳、黑市情报）。**信息要靠消息网跑，不靠天象通知全世界。**
- **高阶修士的感应例外**：化神以上修士神识敏锐，**新道则出世时道韵扩散，他们能同时感应到**——这一条合理，保留；但要写成"感应到一缕从未有过的道韵"，而不是"天生异象，人人皆见"。

## 四、人物谱系与关系网络

### 4.1 主角

**楚尘**：地球穿越者，转世苍云城楚家。开局遭遇退婚、族内羞辱、逐出家门三连打击。绝境中得上古武道大宗师残魂传功，走上武道之路；卷二灵根解封、混沌灵根觉醒，正式开启仙武双修。性格豪爽重情，喜好结交朋友，敌人众多，追随者和生死兄弟同样众多。最终以圣武圆满之躯渡过天劫，仙武双修同时登顶，获"武神"称号，成为千万年来第一个飞升者。

- **反差点**：被判定"灵根枯竭的废物"，却走出万年来唯一的武道飞升路。
- **底层欲望**：不是复仇，是"我要证明——道不只看灵根"；尊严与问道并存。
- **成长终点**：从为自己正名，到为众生开路（道即众人）。
- **性格标签**：豪爽、重情、坚韧、敢赌、有现代人的平视视角。

### 4.2 关键传承者

**残魂（上古武道大宗师）**：千万年前飞升渡劫失败的上古武道大宗师，魂魄残片被封于一件残破法宝中。楚尘在城外荒山偶然捡到该法宝，残魂在消散前将毕生所修的上古武道功法倾囊相授。残魂传功是楚尘武道之路的起点，其完整传承成为全书新功法体系的基础。登场于卷一（第 3-4 章），传功后即消散，不再直接参与后续剧情；卷二第 97 章法宝碎片曾最后一次共鸣回响；其身份在卷六上古地宫（第 335 章）中被彻底揭示——残魂所传是上古武道最后一脉完整传承，是千万年功法断层中唯一幸存的上古完整体系。

**断岳（上古丹武武者·传承）**：裂天峡谷石碑的留下者，卷二第 74-75 章以石碑形式登场，完整记录丹武突破三才条件；卷六第 336 章武神祭坛上其丹武心法全本出世。

### 4.7 反派与对立阵营谱系

本书无系统、无面板。"金手指"为残魂传功，于第 3-4 章亮相，只展示极简功能（明劲入门法门＋意志淬炼理念），不一次性倒出全部设定；残魂的身份与"千万年断绝"之谜作为长线悬念保留至卷六第 335 章揭示。

1. 楚尘转世苍云城楚家，遭退婚、羞辱、逐出家门。

## 十二、写作准则与质量控制

### 12.1 境界推进准则

1. **卷内小阶推进**：每大境的四小阶（前/中/后/圆满）必须依次走完，绝不跨小阶。
2. **卷间大境衔接**：卷末境界即下卷起点境界，无境界回退，无跳跃衔接。
3. **仙武双修节奏**：卷二开启双修后武道与仙道齐头并进；**卷三仙道推进较快（炼气一层→金丹圆满），每次突破必须完整交代突破铁律四条与底蕴来源（上古完整传承补残缺／苦修与实战的绝对量／丹药与外物），避免练级感**。炼气段一律按**层数**写（一至九层），并守住"炼气不能离地飞行"的硬设定。
4. **突破铁律优先（最高优先级）**：每一次楚尘的境界突破，一律按 3.4 落地——**深厚底蕴＋具体奇遇或豁然贯通的契机＋水到渠成＋成境后同阶偏强一档**；**不写任何突破代价、反噬、后遗症、恢复期、修为倒退**；严禁"练得差不多了顺势突破""时机成熟自然突破""硬撑破关"等含糊或勉强的写法。战斗受的伤、渡劫与大战之伤、剧情牺牲与损失、其他人物（配角/反派）突破或强行提升所付的代价，一律照写照留（见 3.4.3）。
5. **飞升时机**：卷七收尾章前须完成大乘静默感应，飞升作为**全书终章**呈现，非中卷事件。
6. **旧稿章号对照**：卷二沿用旧稿章号（61-130）；卷三至卷七旧稿章号一律 +25 换算（旧 106-405 → 新 131-430），其中旧卷六前半（286-345）归新卷六、旧卷六后半（346-405）归新卷七。素材与本大纲的境界、人物状态表述不一致时，以本大纲为准；"突破代价／反噬／后遗症"一律不写，以 3.4 突破铁律为准。

### 12.2 全书一致性检查项（每卷完成后执行）

- [ ] **体系路径**：主角及核心人物的体系进度是否符合 2.4 全书境界表
- [ ] **突破铁律**：本卷每一次楚尘的突破是否满足 3.4 四条——底蕴（完整传承／苦修量／药材外物是否给出具体量级与来路）、契机（是否为具体有分量的奇遇或豁然贯通，而非含糊/勉强）、过程（是否顺、稳、痛快）、成境后是否以同阶对照或旁人评价写出"偏强一档"
- [ ] **无突破代价**：全卷是否残留任何"因突破本身"产生的代价／反噬／后遗症／恢复期／真力枯竭／经脉受损／道基虚浮／修为倒退表述（战斗伤、渡劫伤、剧情牺牲、其他人物的代价不在清理范围）
- [ ] **战力关系**：体系间战力规则、越级挑战规则（第三部分硬约束）是否一致；卷一至卷二前半是否越过 3.3.1 A 表三条硬顶（明劲巅峰／暗劲巅峰／化劲圆满）
- [ ] **炼气层数与飞行**：炼气修为是否按**层数**落笔（不用"炼气中期偏上"这类含糊说法）；是否出现**炼气期修士飞行、凌空、腾空久驻、御剑载人**的描写（一律不允许，离地飞行自筑基起）
- [ ] **动静量级与来源**：本卷每一处大动静是否与境界相称、是否写清来源（遗迹之力／道则／他自己的拳）；是否残留"天地异象／异象震天／天地为之变色"等空话；除飞升渡劫外是否残留"雷劫／天罚"
- [ ] **人物命运**：各人物状态是否按 4.9 命运总表推进
- [ ] **伏笔状态**：对照第九部分伏笔总表，埋设是否到位、回收是否合理
- [ ] **世界观边界**：是否违反 1.3 硬边界（无系统、无天道化身、无飞升封印）
- [ ] **因果逻辑**：事件因果链是否完整闭环

### 12.3 情绪节奏检查（每章/每卷）

- 3-5 章小爽点／10-15 章中高潮／30 章大反转
- 一章 = 一个核心事件；章末最后 200 字留钩子
- 紧张段（危机/抉择）与舒缓段（细节/关系/伏笔）交替，参照 8.3 情绪曲线
