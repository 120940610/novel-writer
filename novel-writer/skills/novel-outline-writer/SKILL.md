# 网文写作大纲生成技能（Novel Outline Writer）

> 核心心法：**开篇钩子留住路人 + 全程情绪牵动读者 + 立体群像支撑长篇 + 名场面引爆二创破圈。**
> 底层公理：**共情 ＞ 期待 ＞ 设定 ＞ 文笔。**

---

## 一、市场洞察：热门类型与趋势（2025–2026）

### 1. 主流类型占比（起点三江榜统计）

| 大类 | 占比 | 主流子赛道 |
|---|---|---|
| **都市** | 27.6% | 华娱+年代+重生、神豪、美利坚背景、刑侦 |
| **历史** | 19.3% | 大明（占历史1/5）、三国、大唐、名著IP改编 |
| **仙侠** | 17.3% | 西游流、苟道长生流、洪荒、稳健流 |
| **轻小说** | 16.1% | 日漫/美漫IP二创、性转/病娇、抽象乐子人 |
| **玄幻** | 10.3% | 高武、面板流、无敌流、唯我独法 |
| 游戏/诸天/科幻 | 5%–6% | LOL/电竞、克苏鲁混搭、文明视野科幻 |

### 2. 番茄 × 中国新闻周刊《2025网文十大关键词》
**无CP大女主、发疯文学、考据式穿越、人性博弈、东方美学叙事、名场面、修仙2.0、短剧改编、人均小说家、秦海璐书单。**

### 3. 两个值得抓住的叙事转向
- **博弈型叙事**：从"爬天梯式升级"转向"封闭循环内爆式生存博弈"，对应00后"幸存"经验（如《十日终焉》《诸神愚戏》）。爽感来源从"进取"变为"幸存"。
- **公路文/疗愈型**：在高度竞争现实中寻求心灵出走，于漫游中疗愈。

### 4. 选题定位实操建议
- **新人优先选大盘赛道**（都市/历史/仙侠/玄幻），读者池大、容错高；冷门题材需文笔惊艳才能破圈。
- **在热门赛道里找细分差异**，避免纯跟风：如"大明"热度高，可叠加"考据式穿越""女性视角""美食种田"形成辨识度。
- **盯平台特性**：番茄偏好极致快节奏、情绪前置；起点付费读者更看重人设与逻辑，节奏可稍缓但300字内须明确主角身份与困境。
- **自查 IP 改编潜力**：短剧/漫剧/影视适配度高的作品更易获得平台资源倾斜。

## 二、破圈核心三要素：情绪 · 群像 · 钩子

这三点比文笔、套路、字数更能决定能否爆。

### 1. 情绪——网文的命脉
网文本质是**售卖情绪价值**，而非讲故事。
- **每一章尽量带出明确情绪**：压抑→期待翻盘、爽快解压、揪心危机、温暖治愈。
- **情绪闭环公式**：制造期待 → 落差 → 反转（给甜枣→扇巴掌→给惊喜）。
- **共鸣优先于冲突**：戳中普遍痛点（裁员、被轻视、内耗、原生家庭），让读者3秒内产生"我也是这样"的代入。

### 2. 群像——决定能否做大
- 单人叙事只能小范围小火；**立体群像才能支撑长篇热度**。
- 配角、反派、路人都要有**立场、私心、执念、过往秘密**，主动推动剧情。
- 番茄神启计划明确要求："配角是读者入坑的多个入口"，用丰满群像吸引多元读者。

### 3. 钩子——决定能否留住路人
- **开篇钩子**（前300字）：抛冲突/危机/不公，一秒抓住。
- **章中钩子**：摒弃"只在章末留悬念"，采用"开篇爆钩 + 章中每千字1个小钩子 + 章末强钩子"组合。
- **章末钩子**：卡在关键节点（真相将揭、变故突生、半句关键信息），**不要把事写圆满**。

## 三、开篇生死线：从"黄金三章"到"黄金300字"

### 平台冷启动数据漏斗（所有开篇的根）
新书经三轮硬性筛选：**500人曝光 → 1000人完读 → 3000人留存**，单向下行，无"后期补救"通道。头部大神靠粉丝兜底，**新人唯一筹码是开篇硬实力**。

### AIDMA 黄金 2000 字金字塔（移动端迭代版）

| 字数段 | 阶段 | 核心任务 |
|---|---|---|
| **0–300字** | A 抓注意 | 单一主角视角，第一段直接砸危机（羞辱/欠债/濒死/背叛/淘汰）。禁大段回忆与景物。 |
| **300–700字** | I 激发兴趣 | 借危机立人设，明确底层欲望（赚钱/复仇/守护/破阶层）；绝境触发金手指，极简讲清功能。 |
| **700–1500字** | D 唤起欲望 | 反派登场加码，加限时枷锁（三日还债/三日后比武/即刻追杀）。世界规则通过对话/路人带出，绝不单独开设定段。 |
| **1500–2000字** | M 留存记忆 | 兑现第一次小爽点宣泄，留下新危机钩子。 |

### 前三章情绪闭环（3000字放量分水岭）
**绝境压迫 → 金手指激活 → 初次反击打脸 → 留下新危机**。这一关决定平台是否放量。

### 黄金三章的差异化逻辑
- **第一章立落差**：巅峰→谷底，收割共情（《斗破苍穹》萧炎天才→废柴；《琅琊榜》林殊→梅长苏）。
- **第二章埋秘密**：制造信息差，给读者"上帝视角特权"（《诡秘之主》换魂无人知晓；《哈利·波特》只有读者懂哈利是天生魔法师）。
- **第三章兑爽点**：先还一笔小账，再铺长线大局。**绝不贪心**，不堆世界观。

### 开头五法（核心一字：打破）
1. 抛出一个**说不通的画面**（解释是悬念的天敌）。
2. 用**反差**制造"这怎么可能"（身份与行为错位）。
3. **跳过铺垫**，第一句就进入冲突。
4. **第一句亮世界观**：用习以为常的语气说极其荒诞的事，越平静越震撼。
5. 第一段让读者**血压上来**：写不公，不是写惨；付出与回报落差越大越好。

## 四、大神套路拆解（可直接套用）

### 1. 反转四招
1. **逻辑误导法**：先给合理假象，再揭真实动机。所有行为不变，变的是背后动机——让读者自己骗自己。
2. **人设底色置换**：让最不可能的人做最不可能的事。先立A面埋违和感，高潮揭开B面。**有伏笔的反转叫烟花，没伏笔的叫炸糖。**
3. **多重反转套娃**：假象→真相→真相是另一假象的掩护，每层留消化空间，最终反转解释前面所有不合理。

### 2. 高潮六招
1. **多线汇聚**：至少三条线同时引爆。
2. **极限压抑**：让主角把苦吃透，情绪弹簧压到底。
3. **多重buff叠加**：时间压力+自身限制+社会压力同时压下。
4. **信息差反转**：翻盘手段必须是前文埋过的伏笔——养成伏笔清单。
5. **侧面烘托**：写围观群众反应，别光写主角。
6. **情绪余韵**：打完别急着收，用地位反差+温情余韵收尾。

### 3. 反派三种（永远别为衬托主角削弱反派）
- **棋手型**：双重目的、借刀杀人、留一个没算到的变量。
- **殉道者**：目的高尚手段残忍，信念比主角更纯粹——读者停下来想，角色就立住了。
- **影子型**：藏在主角身边，前期越可靠，每件好事背后埋伏笔，真相大白时主角人生观被否定。

### 4. 死亡三种（前提：想让读者哭，先让读者爱上角色）
- **差一点的遗憾**：铺垫期待→给希望→最高点掐灭；细节越日常越扎心。
- **带着误解死亡**：让读者先恨他、再后悔恨过他——制造误解→带着骂名死→逐步揭开→情绪反转。真相越慢越狠。
- **极致的平淡**：不写死亡写空缺——习惯性呼唤、多买一份、成功时的缺席。

### 5. 画面感四法
1. 模糊词换具体画面（颜色/材质/形状）。
2. 远景→中景→特写，像导演推进镜头。
3. 铺垫用长句，转折高潮换短句（长句拉弓，短句放箭）；删掉"的、了、着"。
4. 至少两种感官，触觉和嗅觉最易被忽略也最建代入感。

## 五、节奏与结构规划

### 情绪节奏
- **每3–5章**一个小爽点
- **每10–15章**一个中高潮
- **每30章**一个大反转
- 单章结构：开头快速进入→中间推进→结尾留悬念，**一章一个核心事件**。

### 张弛循环
紧张段（危机/抉择/发难）与舒缓段（细节/关系/伏笔/调情绪）**交替进行**，杜绝全程打斗疲劳或长期平淡流失。

### 中后期防崩
- 失衡主因：全程冲突扎堆 或 长期平淡无变化。
- 解法：持续制造"新变化"，每卷给主角一个新目标/新对手/新世界层级。

## 六、快速破圈实战清单

**选题**
- [ ] 选大盘赛道（都市/历史/仙侠/玄幻）打底，叠加一个差异化细分点
- [ ] 自查是否具备IP改编潜力（短剧/漫剧/影视适配度）

**开篇**
- [ ] 前300字砸出绝境，单一主角视角
- [ ] 1000字内落地金手指/翻盘资本，背景设定合计≤100字
- [ ] 3000字走完一轮情绪闭环（压迫→激活→反击→新钩子）
- [ ] 前10句话明确：类型、主角性格、核心爽点

**留客**
- [ ] 每章带明确情绪落点
- [ ] 章中每千字1个小钩子 + 章末强钩子，不留"写圆满"
- [ ] 立体群像：每个重要配角有立场/私心/秘密

**人设**
- [ ] 主角复杂饱满，有清晰成长弧线（读者铭记"成为什么样的人"而非战力数值）
- [ ] 反派不工具化，越强则胜利越有含金量
- [ ] 制造"名场面"——可被二创、被截图传播的高光

**平台运营**
- [ ] 按平台调节奏（番茄极致快、起点重逻辑）
- [ ] 稳定日更（断更是流量杀手）
- [ ] 书名含核心卖点，简介三句话：主角是谁、遇到什么、要干什么
- [ ] 积极与读者互动，评论区是二次传播场

## 七、执行流程（AI 调用本 skill 时按此推进）

当用户请求生成写作大纲时，按以下步骤输出：

### Step 1：选题定位
1. 询问/确认：题材大类、目标平台、主角性别、是否有 CP、字数规模。
2. 基于本 skill 第一章给出 2–3 个细分赛道建议，每个标注：差异化点、读者池大小、IP 潜力。

### Step 2：核心卖点提炼
输出一句话核心卖点（书名雏形）+ 简介三句话（主角是谁、遇到什么、要干什么）。

### Step 3：主角与群像设计
- 主角：人设反差点 + 底层欲望 + 成长弧线终点（成为什么样的人）。
- 反派：从"棋手/殉道者/影子"三型中选定，给出信念与变量。
- 关键配角 2–3 个：立场、私心、秘密。

### Step 4：开篇 AIDMA 大纲
按 0–300 / 300–700 / 700–1500 / 1500–2000 字段，逐段写明：危机、人设落点、金手指标注、反派加码、小爽点、章末钩子。再补第三章"兑爽点 + 长线悬念"。

### Step 5：节奏结构规划
- 小爽点（3–5章）/中高潮（10–15章）/大反转（30章）的排布示意。
- 第一卷（约30章）的分章钩子清单。

### Step 6：破圈自查清单
对照本 skill 第六章逐项打勾，标出未达标项并给出修改建议。

### Step 7：名场面设计
给出 2–3 个可被二创/截图传播的高光场景草案（情绪+反差+视觉画面）。
