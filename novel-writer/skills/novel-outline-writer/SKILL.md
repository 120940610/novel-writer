# 网文写作大纲生成技能（Novel Outline Writer）

> 核心心法：**开篇钩子留住路人 + 全程情绪牵动读者 + 立体群像支撑长篇 + 名场面引爆二创破圈。**
> 底层公理：**共情 ＞ 期待 ＞ 设定 ＞ 文笔。**

---

## 一、市场洞察：热门类型与趋势（2025–2026）

### 1. 主流类型占比（起点三江榜统计）

| 大类 | 占比 | 主流子赛道 |
|---|---|---|
| **都市** | 27.6% | 华娱+年代+重生、神豪、美利坚背景、刑侦 |
| **历史** | 19.3% | 大明（占历史1/5）、三国、大唐、名著IP改编 |
| **仙侠** | 17.3% | 西游流、苟道长生流、洪荒、稳健流 |
| **轻小说** | 16.1% | 日漫/美漫IP二创、性转/病娇、抽象乐子人 |
| **玄幻** | 10.3% | 高武、面板流、无敌流、唯我独法 |
| 游戏/诸天/科幻 | 5%–6% | LOL/电竞、克苏鲁混搭、文明视野科幻 |

### 2. 番茄 × 中国新闻周刊《2025网文十大关键词》
**无CP大女主、发疯文学、考据式穿越、人性博弈、东方美学叙事、名场面、修仙2.0、短剧改编、人均小说家、秦海璐书单。**

### 3. 两个值得抓住的叙事转向
- **博弈型叙事**：从"爬天梯式升级"转向"封闭循环内爆式生存博弈"，对应00后"幸存"经验（如《十日终焉》《诸神愚戏》）。爽感来源从"进取"变为"幸存"。
- **公路文/疗愈型**：在高度竞争现实中寻求心灵出走，于漫游中疗愈。

### 4. 选题定位实操建议
- **新人优先选大盘赛道**（都市/历史/仙侠/玄幻），读者池大、容错高；冷门题材需文笔惊艳才能破圈。
- **在热门赛道里找细分差异**，避免纯跟风：如"大明"热度高，可叠加"考据式穿越""女性视角""美食种田"形成辨识度。
- **盯平台特性**：番茄偏好极致快节奏、情绪前置；起点付费读者更看重人设与逻辑，节奏可稍缓但300字内须明确主角身份与困境。
- **自查 IP 改编潜力**：短剧/漫剧/影视适配度高的作品更易获得平台资源倾斜。

## 二、破圈核心三要素：情绪 · 群像 · 钩子

这三点比文笔、套路、字数更能决定能否爆。

### 1. 情绪——网文的命脉
网文本质是**售卖情绪价值**，而非讲故事。
- **每一章尽量带出明确情绪**：压抑→期待翻盘、爽快解压、揪心危机、温暖治愈。
- **情绪闭环公式**：制造期待 → 落差 → 反转（给甜枣→扇巴掌→给惊喜）。
- **共鸣优先于冲突**：戳中普遍痛点（裁员、被轻视、内耗、原生家庭），让读者3秒内产生"我也是这样"的代入。

### 2. 群像——决定能否做大
- 单人叙事只能小范围小火；**立体群像才能支撑长篇热度**。
- 配角、反派、路人都要有**立场、私心、执念、过往秘密**，主动推动剧情。
- 番茄神启计划明确要求："配角是读者入坑的多个入口"，用丰满群像吸引多元读者。

### 3. 钩子——决定能否留住路人
- **开篇钩子**（前300字）：抛冲突/危机/不公，一秒抓住。
- **章中钩子**：摒弃"只在章末留悬念"，采用"开篇爆钩 + 章中每千字1个小钩子 + 章末强钩子"组合。
- **章末钩子**：卡在关键节点（真相将揭、变故突生、半句关键信息），**不要把事写圆满**。

## 三、开篇生死线：从"黄金三章"到"黄金300字"

### 平台冷启动数据漏斗（所有开篇的根）
新书经三轮硬性筛选：**500人曝光 → 1000人完读 → 3000人留存**，单向下行，无"后期补救"通道。头部大神靠粉丝兜底，**新人唯一筹码是开篇硬实力**。

### AIDMA 黄金 2000 字金字塔（移动端迭代版）

| 字数段 | 阶段 | 核心任务 |
|---|---|---|
| **0–300字** | A 抓注意 | 单一主角视角，第一段直接砸危机（羞辱/欠债/濒死/背叛/淘汰）。禁大段回忆与景物。 |
| **300–700字** | I 激发兴趣 | 借危机立人设，明确底层欲望（赚钱/复仇/守护/破阶层）；绝境触发金手指，极简讲清功能。 |
| **700–1500字** | D 唤起欲望 | 反派登场加码，加限时枷锁（三日还债/三日后比武/即刻追杀）。世界规则通过对话/路人带出，绝不单独开设定段。 |
| **1500–2000字** | M 留存记忆 | 兑现第一次小爽点宣泄，留下新危机钩子。 |

### 前三章情绪闭环（3000字放量分水岭）
**绝境压迫 → 金手指激活 → 初次反击打脸 → 留下新危机**。这一关决定平台是否放量。

### 黄金三章的差异化逻辑
- **第一章立落差**：巅峰→谷底，收割共情（《斗破苍穹》萧炎天才→废柴；《琅琊榜》林殊→梅长苏）。
- **第二章埋秘密**：制造信息差，给读者"上帝视角特权"（《诡秘之主》换魂无人知晓；《哈利·波特》只有读者懂哈利是天生魔法师）。
- **第三章兑爽点**：先还一笔小账，再铺长线大局。**绝不贪心**，不堆世界观。

### 开头五法（核心一字：打破）
1. 抛出一个**说不通的画面**（解释是悬念的天敌）。
2. 用**反差**制造"这怎么可能"（身份与行为错位）。
3. **跳过铺垫**，第一句就进入冲突。
4. **第一句亮世界观**：用习以为常的语气说极其荒诞的事，越平静越震撼。
5. 第一段让读者**血压上来**：写不公，不是写惨；付出与回报落差越大越好。

## 四、大神套路拆解（可直接套用）

### 1. 反转四招
1. **逻辑误导法**：先给合理假象，再揭真实动机。所有行为不变，变的是背后动机——让读者自己骗自己。
2. **人设底色置换**：让最不可能的人做最不可能的事。先立A面埋违和感，高潮揭开B面。**有伏笔的反转叫烟花，没伏笔的叫炸糖。**
3. **多重反转套娃**：假象→真相→真相是另一假象的掩护，每层留消化空间，最终反转解释前面所有不合理。

### 2. 高潮六招
1. **多线汇聚**：至少三条线同时引爆。
2. **极限压抑**：让主角把苦吃透，情绪弹簧压到底。
3. **多重buff叠加**：时间压力+自身限制+社会压力同时压下。
4. **信息差反转**：翻盘手段必须是前文埋过的伏笔——养成伏笔清单。
5. **侧面烘托**：写围观群众反应，别光写主角。
6. **情绪余韵**：打完别急着收，用地位反差+温情余韵收尾。

### 3. 反派三种（永远别为衬托主角削弱反派）
- **棋手型**：双重目的、借刀杀人、留一个没算到的变量。
- **殉道者**：目的高尚手段残忍，信念比主角更纯粹——读者停下来想，角色就立住了。
- **影子型**：藏在主角身边，前期越可靠，每件好事背后埋伏笔，真相大白时主角人生观被否定。

### 4. 死亡三种（前提：想让读者哭，先让读者爱上角色）
- **差一点的遗憾**：铺垫期待→给希望→最高点掐灭；细节越日常越扎心。
- **带着误解死亡**：让读者先恨他、再后悔恨过他——制造误解→带着骂名死→逐步揭开→情绪反转。真相越慢越狠。
- **极致的平淡**：不写死亡写空缺——习惯性呼唤、多买一份、成功时的缺席。

### 5. 画面感四法
1. 模糊词换具体画面（颜色/材质/形状）。
2. 远景→中景→特写，像导演推进镜头。
3. 铺垫用长句，转折高潮换短句（长句拉弓，短句放箭）；删掉"的、了、着"。
4. 至少两种感官，触觉和嗅觉最易被忽略也最建代入感。

## 五、节奏与结构规划

### 情绪节奏
- **每3–5章**一个小爽点
- **每10–15章**一个中高潮
- **每30章**一个大反转
- 单章结构：开头快速进入→中间推进→结尾留悬念，**一章一个核心事件**。

### 张弛循环
紧张段（危机/抉择/发难）与舒缓段（细节/关系/伏笔/调情绪）**交替进行**，杜绝全程打斗疲劳或长期平淡流失。

### 中后期防崩
- 失衡主因：全程冲突扎堆 或 长期平淡无变化。
- 解法：持续制造"新变化"，每卷给主角一个新目标/新对手/新世界层级。

## 六、爽感设计：六种情绪释放模型

> 爽感不是主角有多强，而是读者情绪的"有序释放"。**先压后放，反派要强，细节要慢。**

### 爽感三大陷阱
1. **没有"压"就直接"放"**：主角从头无敌，读者无期待无紧张感。拔河比赛一方力量十倍于对方，没有看头。
2. **反派太弱，打脸不疼**：反派是跳梁小丑，击败如大人打小孩，毫无成就感。真正爽感需要强大、有逻辑、让读者恨得牙痒痒的反派。
3. **节奏失衡，爽点太快**：三言两语解决危机，情绪还没发酵就结束了。

### 爽感万能公式
**困境/羞辱 → 反转爆发 → 即时收益/打脸 → 留下期待**

### 六种情绪释放模型

#### 1. 自尊补偿爽（全题材通用，最基础）
人性本能厌恶被轻视。写法：贬低天赋/当众嘲讽/身份碾压 → 主角隐忍蓄力 → 当众反转、实力碾压 → 反派惊恐后悔、旁人敬畏震撼。
> 适合所有开篇、打脸桥段，是最稳定、最不会出错的基础爽点。

#### 2. 越级碾压爽（成瘾最强）
拉大阶级/修为/权势差距，塑造傲慢轻敌的高位敌人，底层主角完成反杀。重点刻画敌人从轻蔑→不屑→震惊→绝望的心理变化，爽感层次最高。

#### 3. 资源收获爽（多巴胺直给）
多人争夺、强敌觊觎、机缘稀缺，所有人求而不得，最终全部归于主角。宝物、功法、血脉、气运、财富——直观满足获得感。

#### 4. 复仇清算爽（情绪宣泄最强）
仇恨是最持久的情绪燃料。提前预埋背叛、暗算、灭门、背刺 → 长期压抑情绪 → 拉长隐忍周期。压抑越久，清算越狠，读者宣泄感越彻底。**切忌复仇过快、仇恨过浅。**

#### 5. 身份反转爽（高光名场面）
废柴/弃子/底层小人开局，后期曝光隐藏身份、古老血脉、隐秘底牌。利用巨大反差制造全场震撼，塑造全书高光时刻，记忆点极强。

#### 6. 护短守护爽（情感粘性最高）
亲人/爱人/下属陷入危机，主角孤身入局、强势护短，一人抗万敌。温柔且强大的人设最容易留住女性读者与情感向读者。

### 痛痒爽三要素循环
> **先痛点引发共情 → 再痒点维持悬念 → 最后爽点释放情绪。** 一本书 = 一轮又一轮情绪引擎。

| 阶段 | 要素 | 操作 | 读者反应 |
|---|---|---|---|
| 开局 | 痛点 | 主角被欺压、被轻视 | "太惨了，替他憋屈" |
| 中段 | 痒点 | 身世秘密、未解谜团 | "到底怎么回事？" |
| 高潮 | 爽点 | 揭开真相、逆袭打脸 | "太爽了！" |

### 震惊流万能公式（3步写出"让读者拍桌"的剧情）
1. **一次反常识操作**：主角做一件"跟行业规矩对着干"的事（修仙用唢呐、考试用逆向思维），勾住好奇心。
2. **三层质疑升级**：同级嘲讽 → 上级否定 → 权威放话立flag，把读者"替主角不平"的情绪憋满。
3. **一波震惊扩散**：对手先懵 → 长辈破防 → 全场炸裂，让爽感像水波一样扩散开来。

### 开篇爽点造法（小白友好）
前300–800字：前100字摆出低谷/难堪/危机 → 中间200–400字主角亮底牌翻盘 → 结尾100字拿好处、震慑对手、引出新目标。

## 七、追读粘性：让读者欲罢不能

### 追读的底层逻辑
追读感不是"写得精彩"，而是读者看完这一章后，心里自动冒出"下一章呢？"的生理冲动。**追读感不是写出来的，是设计出来的。**

### 核心结构公式：目标—阻碍—反馈—新悬念
- **目标**：让读者知道主角想要什么（没有目标的主角最易把剧情写散）。
- **阻碍**：不能让主角轻松达成，必须制造持续压力。
- **反馈**：主角努力后给阶段性成果（即时反馈），不给读者"白看了"的挫败感。
- **新悬念**：在反馈之后立刻抛出新的不确定性，形成持续牵引。

### 钩子设计的七大类型

| 类型 | 核心特征 | 示例 | 适用场景 |
|---|---|---|---|
| **悬念钩** | 章末抛出未解之谜 | "门后坐着的，竟然是三天前下葬的父亲！" | 悬疑/玄幻/都市异能 |
| **危机钩** | 生死存亡/时间紧迫 | "氧气面罩剩余时间：00:03:27，出口在二十层楼下。" | 战斗/逃生/倒计时 |
| **情感钩** | 情绪爆发/关系转折 | "我从来没有恨过你，我只是…太想你了。" | 言情/都市/青春 |
| **信息钩** | 颠覆认知的重要信息 | "你以为你是穿越者？你只是第十号实验体。" | 伏笔回收/身份揭露 |
| **选择钩** | 两难困境 | "A.拯救全城，爱人必死；B.与爱人双宿双飞，全城陪葬。" | 道德困境/利益冲突 |
| **行动钩** | 预告重大行动 | "明天，就是他们付出代价的时候。" | 复仇/夺宝/比武 |
| **反差钩** | 打破预期 | "别打了，你们欠我的钱什么时候还？" | 反套路/喜剧/轻松向 |

### 钩子黄金法则
- **位置法则**：章节末尾最后200字 = 黄金钩子位
- **密度法则**：每3章1个小钩子，每10章1个中钩子，每30章1个大钩子
- **类型法则**：七大类型交替使用，避免单一重复
- **兑现法则**：埋下的钩子必须在3–5章内给出回应，最长不超过10章

### 四层情绪拉扯（读者追更上瘾）
1. **第一层：期待落差对撞**——给希望→泼冷水→再翻盘。一落一起，情绪瞬间被调动。
2. **第二层：理智情感博弈**——让角色两难，让读者共情。理智说A，情感要B，正邪对立、爱恨相冲。
3. **第三层：信息差错位**——读者知情，主角不知情。制造"上帝视角的焦虑"，读者越看越急越想往下翻。
4. **第四层：灵魂共鸣升华**——跳出小情小爱，触及宿命与信仰（如《哪吒》"我命由我不由天"）。让读者在角色身上看到自己。

### 过山车式节奏
- 高能冲突后 → 加一段温馨日常
- 平淡铺垫后 → 再来一次炸裂反转
- 黄金法则：**没有铺垫的冲击，全是廉价爽感。用平静衬激烈，用美好衬遗憾。**

### 钩子自检三问
1. 有没有让读者**担心**？——不是担心剧情是否精彩，而是担心角色会不会出事。
2. 代价够不够**具体**？——"输了会很难堪"不够，换成"输了唯一的亲人会被带走"。
3. 结尾够不够让人**不舒服**？——每章结尾要让读者有一点不舒服，必须点下一章才能缓解。

## 八、反转与伏笔：让读者惊呼"原来如此"

### 反转的本质
> 反转不是"读者猜不到"，而是"读者回头翻时发现早就写好了"。**有伏笔的反转是烟花，没伏笔的反转是炸糖。**

### 四种神级反转（可直接套用）

#### 1. 灯下黑反转：利用读者惯性，制造思维盲区
先布置足量合理的烟雾弹，让读者笃定自己猜对剧情，再一举颠覆所有预判。全程逻辑闭环。
- **案例**：主角救下落魄首富，对方送资源、给人脉、扶持创业——读者以为是"贵人相助"爽文开局。反转：首富看中的是主角独一无二的特殊命格，所有扶持都是为了养熟命格、养旺时机，最后一举收割为自家后代逆天改命。

#### 2. 剥洋葱反转：逐层颠覆人设
先不断加固人物固定标签，让读者彻底固化印象，再层层撕开伪装、颠覆内核。每一次揭秘都带来全新冲击。
- **案例**：宗门里温柔慈悲的白衣师尊，从不杀生，心怀苍生。反转：她从不杀生不是心善，而是依靠吸纳普通人的善意和气运修炼。越是温柔护人，吸纳的底蕴越多。圣人皮囊藏着掠夺一切的本心。

#### 3. 期待值反向对冲：情绪拉扯，爽感翻倍
先拉高读者期待 → 狠狠打压情绪 → 最后极致反杀。先抑后扬，普通打脸变碾压级体验。
- **案例**：豪门晚宴主角亮出千万合同准备打脸 → 对手揭穿合同是伪造的，主角沦为笑柄 → 读者情绪跌入谷底 → 反转：假合同是主角故意抛出的诱饵，目的就是逼对手当众核验，顺势曝光其偷税漏税、商业造假全部黑料。

#### 4. 因果偷梁换柱：不改剧情，只改动机（最高阶）
不改动任何已经发生的剧情，只颠覆人物行为的初心动机。所有情节全部合理，逻辑毫无漏洞，人物却瞬间立体颠覆。
- **案例**：女二号从主角低谷时不离不弃、默默守护、挡灾避祸、陪主角熬过最艰难的日子。读者认定她深情专一。反转：她所有的守护、牺牲、退让，从来不是因为深爱，而是前世亲手坑害了主角，今生步步守护只为赎罪修身、求得自身圆满。

### 反转三大铁律
1. **伏笔必须在前**：反转的线索必须在前文自然出现过。没有伏笔的反转叫"空降设定"，读者会骂"作者在瞎编"。
2. **逻辑必须闭环**：反转揭露后，读者回看前面会发现所有细节都说得通。
3. **每层留消化空间**：多重反转不要连续炸，每层之间给读者喘口气，才有"回味"的震撼。

### 伏笔四技法（让读者翻回第一章）

**核心认知**：伏笔不是"藏线索等读者发现"，而是"种种子让读者看到但不觉得重要"。伏笔是魔术师的道具——放在明处，让读者视而不见。揭示那一刻，读者恍然大悟："原来早就写了！"

#### 技法1：明处种种子
伏笔的种子不要藏在暗处，放在日常细节里——角色随口说的一句话、一个看似普通的物件、一个无关的小事件。不要加任何强调（不要写"他注意到那个东西似乎有些不同"），就写它本身。读者看到了不觉得重要，这就对了。
- **案例**：《凡人修仙传》韩立随身带的小瓶子，前期就是普通储物容器，读者扫过不会停留，后期却是整本书最重要的时间加速法宝。

#### 技法2：分次浇灌
不要一次说完，分多次透露：第一次提及存在 → 第二次给更多细节 → 第三次接近真相 → 最后完全揭晓。越重要的伏笔，浇灌周期越长。

#### 技法3：契诃夫之枪——一把枪两次响
第一声枪响在剧情里（物理上的开火），第二声枪响在角色心里（心理上的影响）。让伏笔不止一个作用，至少两到三个：一次推动剧情，一次塑造人物，一次铺垫后续。
- **案例**：受害者发出求救——第一声响：被凶手听到，塑造凶手性格（恼羞成怒→认识受害者求救对象→引出兄弟设定）；第二声响：被证人模糊听到但没引起重视，为后续冤案埋下伏笔。

#### 技法4：余韵回响
揭示之后不要急着收工，让伏笔的余韵继续影响后续剧情一两章。给读者足够的时间在评论区讨论、回味、翻回前面找证据。

### 伏笔 vs 悬念（核心区别）
- **悬念向前看**："主角能不能打赢？"——读者追着往下看，属于**好奇驱动**。
- **伏笔向后看**："原来第一章就暗示了！"——读者翻回前面看，属于**认知驱动**。
- 悬念是让读者"我不知道"，伏笔是让读者"原来我早就知道了但没意识到"。

## 十、武道体系与全书自洽：逻辑零BUG 的硬核铁律

> 设定可以天马行空，但**一旦写下，就是铁律**。全书逻辑自洽的程度，决定读者能追多远。

### 铁律一：武技/功法必须有来源

**任何有名有姓的武技功法首次出现，必须先交代来源。** 来源必须是以下三者之一：

| 来源类型 | 说明 | 示例 |
|---|---|---|
| **残念传承** | 从古遗迹/残魂/玉简/石碑中获得，有明确出处 | "在古墓第三层石壁上，他得到了刻满剑痕的《残阳九剑》" |
| **自创顿悟** | 主角在战斗中/修炼中/生死关头自行领悟，有触发契机 | "被逼入绝境，他忽然想起师父说过的话，刹那间灵气逆行，自创一式'逆脉斩'" |
| **他人所授** | 由师父/长辈/朋友/敌人传授，有具体人物和场景 | "师叔临走前，将毕生所学的《云隐步》口诀刻入他识海" |

**没有来源的武技，一律降格为无名本能描写**：
- 正确："主角体内灵气自行流转，本能地一掌拍出，竟将巨石震裂。"（无名本能，不需要来源）
- 错误："主角施展了一套'裂石掌'，将巨石震裂。"（有名武技但无来源）
- 修正："主角体内灵气自行流转，本能地一掌拍出——这分明是父亲临终前，在他识海中留下的那套《裂石掌》。那一掌的运劲方式，他记得清清楚楚。"（来源：他人所授，来自父亲临终）

**武技来源的叙事价值**：每一次武技来源交代，都是一次世界观展示、人物关系深化或历史伏笔的契机。

### 铁律二：武道境界必须符合发展逻辑

**境界升级的三大硬性条件**（缺一不可）：

1. **能量积累到位**：灵气/真气/内力积累到当前境界的瓶颈。不能凭空跳级。
2. **关键契机触发**：有具体的突破事件（服丹/悟道/生死战/传承/天劫），不能"睡一觉就突破了"。
3. **代价或限制明确**：突破后需要稳固期，有后遗症或使用限制。越级突破必须付出更大代价。

**境界设计的核心原则**：
- **每个境界必须有明确的**：晋级条件、实力表现、寿命变化、社会地位、数量分布（该境界在世界的稀缺程度）。
- **境界差距呈现指数级碾压**：高阶对低阶具备绝对优势，但不能让前期境界完全失去意义。
- **越级挑战有限度**：主角越级不超过2个大境界，且必须有合理原因（金手指/特殊功法/战术克制）。
- **瓶颈真实存在**：突破不是走过场，每一次突破都应该是全书的小高潮。

**武技进阶必须层层递进**：
- 同一个武技名字，每次升级都要有明确的触发事件和效果变化。例如：
  - 第10章：习得《青罡拳》（来源：师父所授）
  - 第50章：《青罡拳》小成——在生死战中领悟，拳风含罡气，可碎铁甲
  - 第120章：《青罡拳》大成——在秘境试炼中突破，拳意化龙形，可破结界
  - 第300章：《青罡拳》圆满——融合自创拳意，返璞归真，一拳既出，天地变色

### 铁律三：动笔前锁定三张基础设定表

这是大神长篇持续更新、逻辑不乱的核心秘诀。

**第一张：世界规则表**
- 宇宙观：世界分层（凡界/灵界/仙界）、地理版图、种族势力
- 力量体系：境界等级（10–15级为宜）、每级条件/能力/寿命/人数
- 核心规则：灵气来源、修炼原理、不可违背的天道法则
- 势力制衡：所有力量、所有阵营必须存在制衡，**没有绝对无敌的势力，也没有绝对无敌的主角**。

**第二张：核心矛盾总纲**
- 一本百万字长篇，**只能有一个终极主线**。
- 全书所有人物恩怨、势力纷争、支线剧情，最终都要汇聚到这一个核心冲突中。
- 确定主线的终极答案（结局），所有章节必须向这个答案推进。

**第三张：完整时间轴**
- 远古铺垫 → 前传伏笔 → 正传四卷 → 结局新纪
- 每一阶段对应明确的时代变化和剧情任务。
- 关键历史事件的时间点固定，后续章节不得随意修改。

### 铁律四：全书一致性——严禁"各写各的"

**这是多人协作/长期连载最常见的崩坏之源。** 必须指定一个"宇宙宪法"（即本 skill 设定表），所有章节必须服从。

**严格的写作纪律**：

1. **宇宙观唯一**：世界的底层规则（灵气来源、天道法则、创世真相）一旦确定，**永远不能修改**。后续章节只能在这个框架内揭示，不能新增矛盾规则。
2. **境界线唯一**：境界等级体系、每个境界的能力边界、越级规则，一经确定即锁定。不能因为"这一章需要主角更强"就临时加一个境界。
3. **结局唯一**：从第一章开始，就必须知道结局。所有伏笔、所有支线、所有角色命运，都是通往结局的铺路石。**结局不是"写到哪算哪"，而是第一章就写好的终点。**
4. **重要事件的因果链唯一**：每个重大事件的发生，必须有前因后果。不能"突然出现一个强者"、"突然掉落一个宝物"、"突然想起来还有这个技能"。

**自检清单——每章发布前必查**：
- [ ] 本章出现的武技/功法有没有来源？（无来源则改为无名描写）
- [ ] 本章的力量展示有没有超出当前境界的能力边界？
- [ ] 本章有没有与之前的设定矛盾？（时间线/人物关系/能力体系）
- [ ] 本章的事件有没有服务于终极主线？（偏离主线超过3章需警惕）
- [ ] 本章的伏笔有没有在设定表中登记？（避免遗忘回收）

### 铁律五：剧情精彩饱满，避免单调乏味

> 读者弃书的首要原因不是"写得不好"，而是"看腻了"。**剧情必须持续制造新鲜感。**

**单调乏味的四大根源与破解之道**：

| 根源 | 表现 | 破解 |
|---|---|---|
| **套路化循环** | 每章都是"遇敌→打不过→突破→打赢" | 变换冲突类型：不只是打斗，加入智斗、谈判、逃亡、探索、解谜 |
| **场景单一** | 连续30章都在同一个宗门/城市 | 每卷换一次场景，新场景=新规则+新人物+新冲突 |
| **情绪单色** | 全程压抑或全程爽 | 过山车节奏：高潮后必接温情/日常，紧张后必接松弛 |
| **角色功能化** | 配角一出场就"助攻"或"找茬" | 给配角独立动机和成长线，让读者期待"这个人接下来会怎样" |

**剧情饱满的五大来源**：

1. **主线推进 + 支线丰富**：主线是骨架，支线是血肉。每次主线推进后，至少展开1条支线（人物关系/势力暗流/世界观探索）。
2. **多线交织**：至少保持3条线并行——主角成长线、势力博弈线、世界观揭示线。三条线交替推进，读者永远有新鲜信息。
3. **场景切换的节奏感**：每3–5章换一种叙事场景（战斗→探索→日常→谈判→修炼→团战），避免同一场景连续超过5章。
4. **信息递进的层次感**：每次揭露的信息量逐级递增，让读者产生"越看越深"的探索感，而不是"一眼看到底"。
5. **反差与意外**：读者以为接下来是A，结果来的是B——但B必须在逻辑上合理。新鲜感来自"意料之外，情理之中"。

**单章饱满度自检**：
- [ ] 本章有没有至少1个新信息？（新人物/新设定/新线索/新矛盾）
- [ ] 本章有没有至少1个情绪变化？（读者情绪不能从头到尾一个调）
- [ ] 本章有没有推动至少1条线？（主线/支线/人物线，不能原地踏步）
- [ ] 本章的场景和上一章是否不同？或同一场景下视角是否不同？

### 铁律六：感情线要曲折离奇，历经磨难

> 最好的感情线，不是"他们在一起了"，而是"他们凭什么在一起"。**感情线本质上是一场关于"信任"的战争。**

**平淡感情线的本质问题**：平铺直叙的感情 = 一见钟情 → 顺风顺水 → 永远甜蜜。读者看完毫无波澜，因为没有任何阻力。

**曲折感情线的核心公式**：
> **吸引 → 误会/冲突 → 分离 → 各自成长 → 终极考验 → 团圆/悲剧**

**感情线的六层磨难（从浅到深）**：

| 层级 | 磨难类型 | 示例 | 叙事作用 |
|---|---|---|---|
| **第一层：身份阻隔** | 阶层/门派/种族/正邪对立 | 正道弟子 × 魔教圣女 | 制造外部压力，建立"禁忌之恋"的刺激感 |
| **第二层：误会隔阂** | 信息不对称导致的误解 | 女主以为男主背叛，实际男主在暗中保护她 | 制造读者焦虑（上帝视角），憋屈→期待澄清 |
| **第三层：立场冲突** | 两人站在对立阵营，必须做出选择 | 家族仇杀、门派之争、皇位之争 | 将感情与宏大叙事绑定，爱恨交织 |
| **第四层：牺牲与成全** | 一方为另一方付出巨大代价 | 散尽修为、放弃皇位、以命换命 | 感情线的高光时刻，读者眼泪来源 |
| **第五层：时间与遗忘** | 失忆、转世、时空错位 | 主角转世后忘记前世爱人 | 最虐心的磨难，读者跟着主角一起"重新认识" |
| **第六层：宿命与对抗** | 两人在一起本身就是对天道的对抗 | "天命注定你们不能在一起" | 将感情线升华为全书主题，触及灵魂共鸣 |

**感情线设计的铁律**：

1. **不要给"完美伴侣"**：对方必须有缺陷、有秘密、有让人恨的地方。读者先恨他/她，再理解他/她，最后爱上他/她。
2. **不要"一见钟情定终身"**：初始好感可以，但必须经历至少两次重大考验才确认关系。**考验越难，在一起越甜。**
3. **不要"没有代价的爱"**：每一次感情进展，都必须付出代价。放弃、牺牲、隐忍——读者记的不是"他们在一起了"，而是"他们为了在一起付出了什么"。
4. **不要在感情线中"开挂"**：感情线的解决方案不能靠金手指。不能用"系统奖励了一个完美伴侣"、不能用"突然觉醒了魅惑体质"。感情线是全书唯一必须靠人物自身成长来解决的线。
5. **给配角感情线留空间**：不是只有主角谈恋爱。配角的感情线（暗恋/背叛/守护/遗憾）可以成为支线，丰富世界观。

**感情线的节奏设计**：
- **初遇**（第5–10章）：建立第一印象，埋下"不对劲"的种子（他/她身上有什么秘密？）
- **第一次危机**（第20–30章）：因误会或立场产生第一次裂痕，读者开始揪心
- **第一次和解**（第35–40章）：误会解除，关系升温，但留下新的隐忧
- **第二次危机**（第60–80章）：更大的冲突——不是误会，而是真正的立场对立。两人必须做出选择。
- **分离期**（第80–120章）：两人分开，各自成长。离别期间，各自经历磨难，但心中始终有对方。
- **终极考验**（第150–180章）：重逢后面对终极考验，一方为另一方做出最大牺牲。
- **结局**：团圆或悲剧——但即使是悲剧，也必须让读者感到"值得"。

**感情线自检清单**：
- [ ] 感情线的磨难是否至少有3层以上？
- [ ] 对方的缺陷/秘密是否足够让读者产生"恨→理解→爱"的情绪转变？
- [ ] 每一次感情进展是否付出了对应的代价？
- [ ] 感情线的解决方案是靠人物成长，还是靠金手指/外挂？
- [ ] 感情线是否与主线深度绑定？（不是"主线之外顺便谈恋爱"）
- [ ] 有没有"名场面"——让读者截图、转发、讨论的高光感情瞬间？

### 铁律七：前期靠传承，后期靠自创——主角必须超越前人

> 金手指是主角的起点，不是终点。**如果主角到结局还在用师父/系统给的东西，那这个故事从一开始就输了。**

**"永远靠外挂"的致命问题**：
- 读者起初会为金手指兴奋，但到中后期会产生审美疲劳："主角除了系统，自己有什么本事？"
- 所有顶级网文都有同一个转折点：**主角从"继承者"变成"开创者"的那一刻，才是全书真正的分水岭。**
- 如果主角从头到尾都是师父的影子、系统的傀儡，成长弧线是平的——他从未真正"成为自己"。

**三阶段成长模型**：

| 阶段 | 章节范围 | 主角定位 | 核心特征 |
|---|---|---|---|
| **继承期** | 前1/3 | 学习者 | 依靠金手指/师父/残魂传承快速成长，消化前人成果 |
| **融合期** | 中1/3 | 探索者 | 开始质疑现有体系，尝试将不同传承融合，萌发自己的理解 |
| **开创期** | 后1/3 | 开创者 | 走出自己的路，自创功法/武技/大道，超越所有前人 |

**继承期的设计要点**（前1/3）：
- 金手指/师父/传承的作用：**降低入门门槛，不是替代主角思考**。
- 师父的正确示范：教心法、教基础、教世界观，但绝不替主角做决定。师父是"引路人"，不是"代练"。
- 师父的合理退场：中前期必须安排师父离开/陨落/沉睡/飞升，让主角失去依靠。**师父不退场，主角永远长不大。**
- 案例：《斗破苍穹》药老——前期教焚诀、教炼药，中期被魂殿抓走，后期萧炎靠自己融合异火、自创佛怒火莲。

**融合期的设计要点**（中1/3）：
- 主角开始问"为什么"：为什么这个功法只能这样练？为什么这个境界不能突破？为什么前人做不到？
- 主角开始做"前人没做过的事"：把两种相克的功法融合、用不同体系的手段解决单一体系的问题。
- 失败的代价：融合期必须有失败。主角尝试创新但失败，付出代价，再从失败中汲取教训。**没有失败的自创，是空中楼阁。**
- 案例：《凡人修仙传》韩立——前期靠小瓶子、靠墨大夫传承，中期开始自创炼器手法、自研傀儡术、摸索属于自己的元婴之路。

**开创期的设计要点**（后1/3）：
- 主角创造的东西，必须超越师父/系统给的一切。**师父的绝招，只是主角新招的垫脚石。**
- 自创的武技/功法必须有一个高光时刻——用自创的招式击败最终BOSS，而不是用师父教的招式。
- 结局呼应：主角最终成为"后人仰望的先辈"，就像他曾经仰望师父一样。传承的闭环完成。
- 案例：《遮天》叶凡——前期靠荒古圣体、靠黑皇、靠狠人大帝传承，后期开创自己的无敌道，一拳打碎一切，成为后世的"叶天帝"。

**三阶段转换的硬性标志**（必须写入大纲）：
1. **师父退场点**（约全书30%处）：师父/金手指的功能性削弱或彻底退场，主角第一次独立面对生死危机。
2. **第一次自创点**（约全书50%处）：主角自创/改良第一招属于自己的武技/功法，明确标注"这一招，是主角自己的"。
3. **超越前人的高光点**（约全书80%处）：主角用自创的成果击败前人所不能击败的敌人，或做到前人所不能做到的事。

**自检清单**：
- [ ] 师父/金手指是否有明确的退场或功能性削弱的时间点？
- [ ] 主角是否在中后期有至少1次自创/改良武技或功法的经历？
- [ ] 最终BOSS是否由主角用"自己的东西"（而非师父/系统给的）击败？
- [ ] 主角最终是否超越了师父/传承的极限，成为后人仰望的开创者？

## 十一、快速破圈实战清单

**选题**
- [ ] 选大盘赛道（都市/历史/仙侠/玄幻）打底，叠加一个差异化细分点
- [ ] 自查是否具备IP改编潜力（短剧/漫剧/影视适配度）

**开篇**
- [ ] 前300字砸出绝境，单一主角视角
- [ ] 1000字内落地金手指/翻盘资本，背景设定合计≤100字
- [ ] 3000字走完一轮情绪闭环（压迫→激活→反击→新钩子）
- [ ] 前10句话明确：类型、主角性格、核心爽点

**留客**
- [ ] 每章带明确情绪落点
- [ ] 章中每千字1个小钩子 + 章末强钩子，不留"写圆满"
- [ ] 立体群像：每个重要配角有立场/私心/秘密
- [ ] 追读结构：目标—阻碍—反馈—新悬念 循环

**爽感**
- [ ] 先压后放，反派够强，细节够慢
- [ ] 痛痒爽三要素循环：痛点→痒点→爽点→再痛→再痒→再爽
- [ ] 开篇爽点300–800字内完成反转闭环

**反转与伏笔**
- [ ] 反转有前文伏笔支撑（不是空降设定）
- [ ] 重要伏笔至少两到三个作用（剧情+人物+后续）
- [ ] 伏笔分次透露，越重要周期越长

**人设**
- [ ] 主角复杂饱满，有清晰成长弧线（读者铭记"成为什么样的人"而非战力数值）
- [ ] 反派不工具化，越强则胜利越有含金量
- [ ] 制造"名场面"——可被二创、被截图传播的高光

**武道体系与自洽**
- [ ] 三张设定表（世界规则/核心矛盾/时间轴）已锁定，不在连载中随意修改
- [ ] 所有有名武技功法首次出现均有来源（残念传承/自创顿悟/他人所授）
- [ ] 境界升级有明确触发事件，不凭空跳级
- [ ] 每章发布前通过自检清单（设定一致性/能力边界/主线关联）

**主角成长与超越**
- [ ] 师父/金手指有明确的退场或功能性削弱时间点（约全书30%处）
- [ ] 主角中后期有至少1次自创/改良武技或功法的经历
- [ ] 最终BOSS由主角用"自己的东西"击败，而非师父/系统给的
- [ ] 主角最终超越前人，成为后人仰望的开创者

**感情线**
- [ ] 感情线经历至少3层磨难（避免平铺直叙）
- [ ] 对方有缺陷/秘密，读者经历"恨→理解→爱"的情绪转变
- [ ] 每一次感情进展付出对应代价，不靠金手指解决
- [ ] 感情线与主线深度绑定，不是"顺便谈恋爱"

**平台运营**
- [ ] 按平台调节奏（番茄极致快、起点重逻辑）
- [ ] 稳定日更（断更是流量杀手）
- [ ] 书名含核心卖点，简介三句话：主角是谁、遇到什么、要干什么
- [ ] 积极与读者互动，评论区是二次传播场

## 十二、执行流程（AI 调用本 skill 时按此推进）

当用户请求生成写作大纲时，按以下步骤输出：

### Step 1：选题定位
1. 询问/确认：题材大类、目标平台、主角性别、是否有 CP、字数规模。
2. 基于本 skill 第一章给出 2–3 个细分赛道建议，每个标注：差异化点、读者池大小、IP 潜力。

### Step 2：核心卖点提炼
输出一句话核心卖点（书名雏形）+ 简介三句话（主角是谁、遇到什么、要干什么）。

### Step 3：主角与群像设计
- 主角：人设反差点 + 底层欲望 + 成长弧线终点（成为什么样的人）。
- 反派：从"棋手/殉道者/影子"三型中选定，给出信念与变量。
- 关键配角 2–3 个：立场、私心、秘密。

### Step 4：开篇 AIDMA 大纲
按 0–300 / 300–700 / 700–1500 / 1500–2000 字段，逐段写明：危机、人设落点、金手指标注、反派加码、小爽点、章末钩子。再补第三章"兑爽点 + 长线悬念"。

### Step 5：节奏结构规划
- 小爽点（3–5章）/中高潮（10–15章）/大反转（30章）的排布示意。
- 第一卷（约30章）的分章钩子清单（七大钩子类型交替）。

### Step 6：爽感设计
- 从六种情绪释放模型中选出最适合本书的 2–3 种主攻方向。
- 设计痛痒爽循环节奏。
- 给出 2 个"震惊流"名场面草案。

### Step 7：反转与伏笔方案
- 设计 1–2 个长线伏笔（"契诃夫之枪"模式，至少两个作用）。
- 设计 1 个核心反转（从四种神级反转中选定类型）。
- 给出伏笔分次透露的时间线。

### Step 8：武道体系与自洽设计
- 根据题材确定三张基础设定表（世界规则/核心矛盾/时间轴）。
- 设计境界体系（10–15级），每级附晋级条件、能力边界、寿命、社会地位、数量分布。
- 列出主角武技/功法清单，每个标注来源（传承/自创/他人所授）和进阶路线。
- 给出"宇宙宪法"核心条款（不可违背的底层规则），作为全书一致性基准。
- 设计主角三阶段成长模型：继承期（前1/3）→ 融合期（中1/3）→ 开创期（后1/3），标注师父退场点、第一次自创点、超越前人的高光点。

### Step 9：感情线设计
- 确认是否有 CP 及感情线的重要程度（主线/支线/无）。
- 设计感情线节奏：初遇→第一次危机→和解→第二次危机→分离期→终极考验→结局。
- 确定感情线经历的磨难层级（至少3层），每层标注具体冲突和情绪效果。
- 设计 1–2 个感情线"名场面"（可被截图转发的高光瞬间）。

### Step 10：剧情饱满度设计
- 设计三线交织结构（主角成长线/势力博弈线/世界观揭示线）。
- 规划场景切换节奏（每3–5章换叙事场景类型）。
- 确保每卷至少1次大场景切换，持续制造新鲜感。

### Step 11：破圈自查清单
对照本 skill 第十一章逐项打勾，标出未达标项并给出修改建议。

### Step 12：名场面设计
给出 2–3 个可被二创/截图传播的高光场景草案（情绪+反差+视觉画面）。
