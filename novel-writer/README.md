# novel-writer

网文写作技能集合。本仓库面向长篇网络小说创作，沉淀可复用的写作 skill。

## 目录结构

```
novel-writer/
└── skills/
    └── novel-outline-writer/
        └── SKILL.md      # 网文写作大纲生成技能
```

## Skills 一览

### novel-outline-writer
基于 2025–2026 网文市场热门类型、大神写作套路与破圈路径的写作大纲生成技能。

- **核心心法**：开篇钩子留住路人 + 全程情绪牵动读者 + 立体群像支撑长篇 + 名场面引爆二创破圈
- **底层公理**：共情 ＞ 期待 ＞ 设定 ＞ 文笔
- **覆盖内容**：
  - 市场热门类型与趋势洞察（都市/历史/仙侠/玄幻/轻小说等占比与子赛道）
  - 破圈三要素：情绪 · 群像 · 钩子
  - 开篇生死线：从"黄金三章"到 AIDMA 黄金 2000 字金字塔
  - 大神套路拆解：反转四招、高潮六招、反派三种、死亡三种、画面感四法
  - 节奏与结构规划
  - 快速破圈实战清单
  - AI 调用执行流程（7 步生成大纲）

## 如何使用

### 作为 AI Skill 使用
将 `skills/novel-outline-writer/SKILL.md` 加载到支持 skill 的 AI 编码/写作助手（如 TRAE）中，向 AI 描述你的创作需求，AI 会按 SKILL.md 第七节执行流程依次输出选题定位、核心卖点、主角群像、开篇 AIDMA 大纲、节奏规划、破圈自查、名场面设计。

### 作为人工写作指南使用
直接阅读 `SKILL.md`，按章节自查你的作品：选题是否在大盘赛道、开篇 300 字是否砸出绝境、每章是否有情绪落点与钩子、群像是否立体、是否设计了可二创的名场面。
